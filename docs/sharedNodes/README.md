# Shared

Shared enumerations referenced from multiple node categories.

## Enumerations

- [`BytesEncoding`](./BytesEncoding.md) - How a string of bytes is encoded for transport.
- [`DefaultValueStrategy`](./DefaultValueStrategy.md) - How an attribute that carries a default value is exposed in generated APIs.
- [`DisplaySkip`](./DisplaySkip.md) - Whether a member should be hidden from the fallback display list.
- [`Endianness`](./Endianness.md) - The byte order of a numeric serialization.
- [`FloatFormat`](./FloatFormat.md) - The wire format of a floating-point serialization.
- [`InstructionLifecycle`](./InstructionLifecycle.md) - The lifecycle stage of an instruction.
- [`IntegerFormat`](./IntegerFormat.md) - The wire format of an integer serialization.
- [`OptionalAccountStrategy`](./OptionalAccountStrategy.md) - How an absent optional account is represented when serialising an instruction.
- [`PostOffsetStrategy`](./PostOffsetStrategy.md) - How a post-offset transform interprets its offset value after serialising the transformed type.
- [`PreOffsetStrategy`](./PreOffsetStrategy.md) - How a pre-offset transform interprets its offset value before serialising the transformed type.
