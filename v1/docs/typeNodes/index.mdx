# Type

Type nodes — the building blocks of every value shape.

## Nodes

- [`AmountTypeNode`](./AmountTypeNode.mdx) - Wraps a number type to provide additional context such as decimal places and a unit.
- [`ArrayTypeNode`](./ArrayTypeNode.mdx) - A homogeneous list of items. The item type is defined by `item`; the length is determined by the `count` strategy.
- [`BooleanTypeNode`](./BooleanTypeNode.mdx) - A boolean serialised as a numeric value. The wrapped number type determines the byte width.
- [`BytesTypeNode`](./BytesTypeNode.mdx) - A raw sequence of bytes. Typically used inside a fixed-size, size-prefixed, or sentinel-terminated wrapper.
- [`DateTimeTypeNode`](./DateTimeTypeNode.mdx) - A timestamp encoded as a number, typically seconds since the Unix epoch. The wrapped number type determines the byte width.
- [`EnumEmptyVariantTypeNode`](./EnumEmptyVariantTypeNode.mdx) - A unit-style variant of an enum that carries no payload.
- [`EnumStructVariantTypeNode`](./EnumStructVariantTypeNode.mdx) - A variant of an enum that carries a struct payload (named fields).
- [`EnumTupleVariantTypeNode`](./EnumTupleVariantTypeNode.mdx) - A variant of an enum that carries a tuple payload (positional fields).
- [`EnumTypeNode`](./EnumTypeNode.mdx) - A tagged union: a numeric discriminator followed by one of several variant payloads.
- [`FixedSizeTypeNode`](./FixedSizeTypeNode.mdx) - Wraps another type and asserts a fixed total byte size. Padding or truncation is applied as needed.
- [`HiddenPrefixTypeNode`](./HiddenPrefixTypeNode.mdx) - Prefixes another type with a list of constant values that are written and read but not surfaced as fields to consumers.
- [`HiddenSuffixTypeNode`](./HiddenSuffixTypeNode.mdx) - Suffixes another type with a list of constant values that are written and read but not surfaced as fields to consumers.
- [`MapTypeNode`](./MapTypeNode.mdx) - A keyed map.
- [`NumberTypeNode`](./NumberTypeNode.mdx) - A numeric type with a fixed wire format and byte order.
- [`OptionTypeNode`](./OptionTypeNode.mdx) - A value that may be present or absent (Some/None), with an explicit numeric prefix indicating presence.
- [`PostOffsetTypeNode`](./PostOffsetTypeNode.mdx) - After serialising the wrapped type, advance the cursor by `offset` bytes interpreted via the chosen strategy.
- [`PreOffsetTypeNode`](./PreOffsetTypeNode.mdx) - Before serialising the wrapped type, advance the cursor by `offset` bytes interpreted via the chosen strategy.
- [`PublicKeyTypeNode`](./PublicKeyTypeNode.mdx) - A 32-byte Solana public key.
- [`RemainderOptionTypeNode`](./RemainderOptionTypeNode.mdx) - A value that may be present or absent. Presence is signalled by whether any bytes remain to be read, with no explicit prefix.
- [`SentinelTypeNode`](./SentinelTypeNode.mdx) - Wraps another type and delimits it with a constant sentinel value written immediately after the wrapped type.
- [`SetTypeNode`](./SetTypeNode.mdx) - A unique-valued collection. The item type is defined by `item`; the size is determined by the `count` strategy.
- [`SizePrefixTypeNode`](./SizePrefixTypeNode.mdx) - Wraps another type with a numeric prefix indicating the byte length of the wrapped type.
- [`SolAmountTypeNode`](./SolAmountTypeNode.mdx) - A SOL amount expressed in lamports under the wrapped numeric type.
- [`StringTypeNode`](./StringTypeNode.mdx) - A string value.
- [`StructFieldTypeNode`](./StructFieldTypeNode.mdx) - A named field within a struct type.
- [`StructTypeNode`](./StructTypeNode.mdx) - A composite type made of an ordered list of named fields. Fields are encoded and decoded in declaration order.
- [`TupleTypeNode`](./TupleTypeNode.mdx) - A heterogeneous fixed-length sequence in which each positional slot has its own type.
- [`ZeroableOptionTypeNode`](./ZeroableOptionTypeNode.mdx) - An optional value whose absence is signalled by a designated zero value rather than a presence flag.

## Unions

- [`EnumVariantTypeNode`](./EnumVariantTypeNode.mdx) - The variant flavours of an `enumTypeNode`.
- [`RegisteredTypeNode`](./RegisteredTypeNode.mdx) - Every node tagged as a type-shaped node, including variants and struct fields.
- [`StandaloneTypeNode`](./StandaloneTypeNode.mdx) - Every type node that can be used as a top-level type.
- [`TypeNode`](./TypeNode.mdx) - The composable form: any standalone type, or a reference to a defined type via `definedTypeLinkNode`.

## Nested unions

- [`NestedTypeNode`](./NestedTypeNode.mdx) - A type, possibly wrapped in zero-or-more size, offset, sentinel, or hidden prefix/suffix modifiers.
