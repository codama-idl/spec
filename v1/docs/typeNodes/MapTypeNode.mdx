# MapTypeNode

A keyed map. The key and value types are described by their respective type nodes; the entry count is determined by a count strategy.

## Attributes

### Data

| Attribute | Type            | Description             |
| --------- | --------------- | ----------------------- |
| `kind`    | `"mapTypeNode"` | The node discriminator. |

### Children

| Attribute | Type                                       | Description                                           |
| --------- | ------------------------------------------ | ----------------------------------------------------- |
| `key`     | [`TypeNode`](./TypeNode.mdx)               | The type of each entry key.                           |
| `value`   | [`TypeNode`](./TypeNode.mdx)               | The type of each entry value.                         |
| `count`   | [`CountNode`](../countNodes/CountNode.mdx) | The strategy used to determine the number of entries. |
