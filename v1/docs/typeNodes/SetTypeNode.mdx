# SetTypeNode

A unique-valued collection. The item type is defined by `item`; the size is determined by the `count` strategy.

## Attributes

### Data

| Attribute | Type            | Description             |
| --------- | --------------- | ----------------------- |
| `kind`    | `"setTypeNode"` | The node discriminator. |

### Children

| Attribute | Type                                       | Description                                         |
| --------- | ------------------------------------------ | --------------------------------------------------- |
| `item`    | [`TypeNode`](./TypeNode.mdx)               | The type of each item in the set.                   |
| `count`   | [`CountNode`](../countNodes/CountNode.mdx) | The strategy used to determine the number of items. |
