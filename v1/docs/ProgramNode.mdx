# ProgramNode

A Solana program: its identity, version, accounts, instructions, defined types, PDAs, events, errors, and constants.

## Attributes

### Data

| Attribute   | Type                    | Description                                 |
| ----------- | ----------------------- | ------------------------------------------- |
| `kind`      | `"programNode"`         | The node discriminator.                     |
| `name`      | `CamelCaseString`       | The name of the program.                    |
| `publicKey` | `Address`               | The base58-encoded program ID.              |
| `version`   | `SemverString`          | The version of the program, in semver form. |
| `docs`      | `string[]` _(optional)_ | Markdown documentation for the program.     |

### Children

| Attribute      | Type                                                            | Description                                                                |
| -------------- | --------------------------------------------------------------- | -------------------------------------------------------------------------- |
| `origin`       | [`ProgramOrigin`](./sharedNodes/ProgramOrigin.mdx) _(optional)_ | The toolchain that originally generated the program description, if known. |
| `accounts`     | [`AccountNode`](./AccountNode.mdx)[]                            | The accounts owned by the program.                                         |
| `instructions` | [`InstructionNode`](./InstructionNode.mdx)[]                    | The instructions exposed by the program.                                   |
| `definedTypes` | [`DefinedTypeNode`](./DefinedTypeNode.mdx)[]                    | The reusable types defined by the program.                                 |
| `pdas`         | [`PdaNode`](./PdaNode.mdx)[]                                    | The PDAs derived by the program.                                           |
| `events`       | [`EventNode`](./EventNode.mdx)[]                                | The events emitted by the program.                                         |
| `errors`       | [`ErrorNode`](./ErrorNode.mdx)[]                                | The errors returned by the program.                                        |
| `constants`    | [`ConstantNode`](./ConstantNode.mdx)[]                          | The constants exposed by the program.                                      |

## Examples

### Create a program node from an input object

```typescript
const node = programNode({
    name: 'counter',
    publicKey: '7ovtg4pFqjQdSwFAUCu8gTnh5thZHzAyJFXy3Ssnj3yK',
    version: '1.42.6',
    accounts: [],
    instructions: [],
    definedTypes: [],
    pdas: [],
    events: [],
    errors: [],
});
```
