# `ArgumentValueNode`

Refers to a named argument of the surrounding instruction.

## Attributes

### Data

| Attribute | Type                  | Description                          |
| --------- | --------------------- | ------------------------------------ |
| `kind`    | `"argumentValueNode"` | The node discriminator.              |
| `name`    | `CamelCaseString`     | The name of the referenced argument. |
