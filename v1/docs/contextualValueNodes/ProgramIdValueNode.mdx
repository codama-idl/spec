# ProgramIdValueNode

Refers to the program ID of the surrounding instruction.

## Attributes

### Data

| Attribute | Type                   | Description             |
| --------- | ---------------------- | ----------------------- |
| `kind`    | `"programIdValueNode"` | The node discriminator. |

## Examples

### Create a program id value node

```typescript
const node = programIdValueNode();
```
