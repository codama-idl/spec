# Value

Value nodes — concrete values whose shape is described by a type node.

## Nodes

- [`ArrayValueNode`](./ArrayValueNode.mdx) - A concrete array value: a list of value nodes.
- [`BooleanValueNode`](./BooleanValueNode.mdx) - A concrete boolean value.
- [`BytesValueNode`](./BytesValueNode.mdx) - A concrete bytes value, encoded as text in the chosen encoding.
- [`ConstantValueNode`](./ConstantValueNode.mdx) - A typed constant: a type node paired with a concrete value node.
- [`EnumValueNode`](./EnumValueNode.mdx) - A concrete value of a defined enum: a variant identifier plus an optional payload.
- [`InjectedValueNode`](./InjectedValueNode.mdx) - A value resolved by key from a surrounding provider.
- [`MapEntryValueNode`](./MapEntryValueNode.mdx) - A single (key, value) pair inside a `mapValueNode`.
- [`MapValueNode`](./MapValueNode.mdx) - A concrete map value: a list of (key, value) entries.
- [`NoneValueNode`](./NoneValueNode.mdx) - The "absent" value for an optional type.
- [`NumberValueNode`](./NumberValueNode.mdx) - A concrete numeric value.
- [`PublicKeyValueNode`](./PublicKeyValueNode.mdx) - A concrete public key, with an optional symbolic identifier for the address.
- [`SetValueNode`](./SetValueNode.mdx) - A concrete set value: a list of unique value nodes.
- [`SomeValueNode`](./SomeValueNode.mdx) - The "present" value for an optional type, wrapping a concrete value node.
- [`StringValueNode`](./StringValueNode.mdx) - A concrete string value.
- [`StructFieldValueNode`](./StructFieldValueNode.mdx) - A named field of a `structValueNode`.
- [`StructValueNode`](./StructValueNode.mdx) - A concrete struct value: a list of named field values.
- [`TupleValueNode`](./TupleValueNode.mdx) - A concrete tuple value: a fixed-length sequence of positional value nodes.

## Unions

- [`EnumValuePayload`](./EnumValuePayload.mdx) - The payload kinds an `enumValueNode` may carry — struct fields or positional tuple slots.
- [`InjectableNumberValueNode`](./InjectableNumberValueNode.mdx) - A concrete number value, or a key resolved at presentation time from a surrounding provider.
- [`InjectableStringValueNode`](./InjectableStringValueNode.mdx) - A concrete string value, or a key resolved at presentation time from a surrounding provider.
- [`RegisteredValueNode`](./RegisteredValueNode.mdx) - Every node tagged as a value-shaped node, including container variants.
- [`StandaloneValueNode`](./StandaloneValueNode.mdx) - Every value node that can be used as a top-level value.
- [`ValueNode`](./ValueNode.mdx) - The composable form: any standalone value node.
