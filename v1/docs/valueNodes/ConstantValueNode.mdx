# ConstantValueNode

A typed constant: a type node paired with a concrete value node.

## Attributes

### Data

| Attribute | Type                  | Description             |
| --------- | --------------------- | ----------------------- |
| `kind`    | `"constantValueNode"` | The node discriminator. |

### Children

| Attribute | Type                                    | Description                         |
| --------- | --------------------------------------- | ----------------------------------- |
| `type`    | [`TypeNode`](../typeNodes/TypeNode.mdx) | The type of the constant.           |
| `value`   | [`ValueNode`](./ValueNode.mdx)          | The concrete value of the constant. |
