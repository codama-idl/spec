# StandaloneValueNode (abstract)

Every value node that can be used as a top-level value.

One of the following:

- [`ArrayValueNode`](./ArrayValueNode.mdx)
- [`BooleanValueNode`](./BooleanValueNode.mdx)
- [`BytesValueNode`](./BytesValueNode.mdx)
- [`ConstantValueNode`](./ConstantValueNode.mdx)
- [`EnumValueNode`](./EnumValueNode.mdx)
- [`InjectedValueNode`](./InjectedValueNode.mdx)
- [`MapValueNode`](./MapValueNode.mdx)
- [`NoneValueNode`](./NoneValueNode.mdx)
- [`NumberValueNode`](./NumberValueNode.mdx)
- [`PublicKeyValueNode`](./PublicKeyValueNode.mdx)
- [`SetValueNode`](./SetValueNode.mdx)
- [`SomeValueNode`](./SomeValueNode.mdx)
- [`StringValueNode`](./StringValueNode.mdx)
- [`StructValueNode`](./StructValueNode.mdx)
- [`TupleValueNode`](./TupleValueNode.mdx)
