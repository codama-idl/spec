Shared enumerations referenced from multiple node categories.

- [`InstructionLifecycle`](./InstructionLifecycle.mdx) - The lifecycle stage of an instruction.
- [`NumberFormat`](./NumberFormat.mdx) - The wire format of a numeric serialization.
- [`OptionalAccountStrategy`](./OptionalAccountStrategy.mdx) - How an absent optional account is represented when serialising an instruction.
- [`PostOffsetStrategy`](./PostOffsetStrategy.mdx) - How a post-offset modifier interprets its offset value after serialising the wrapped type.
- [`PreOffsetStrategy`](./PreOffsetStrategy.mdx) - How a pre-offset modifier interprets its offset value before serialising the wrapped type.
- [`ProgramOrigin`](./ProgramOrigin.mdx) - The toolchain that originally generated a program description.
